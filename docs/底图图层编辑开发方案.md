# 底图图层编辑开发方案

## 目标与范围

在批印坊内完成证书、胸卡和桌牌的常用底图制作。用户可独立创建工程，编辑图片、固定文字与基础形状，保存后应用到批量打印模板。底图工程不依赖名单；变量字段继续由现有模板管理。

第一版交付完整的创建、编辑、保存、应用、预览和 PDF 输出流程。首期不包含 PSD 或 Compositor 工程互开、绘画、复杂滤镜、混合模式与专业印刷色彩管理。

## 源码分析依据

参考仓库 robbietilton/Compositor，提交 af30c45c10b1cddc2b9fe8401c137f250d50abb6。本地位于 `.workbuddy-ai/references/Compositor`。借鉴其素材与变换分离、视口坐标映射、操作级撤销、保存版本快照；不引入 macOS 原生运行时或复制其渲染器。

Compositor 导入会转换 RGBA8/sRGB，SVG 导入即栅格化。批印坊需遵守既有底图保真要求，因此保存原图片字节，预览和 PDF 使用同一份图层布局。合成 PNG 不作为打印的权威输入。

## 用户流程

1. 在「底图制作」新建工程，选择成品宽高、方向和背景色。
2. 添加图片、固定文字、矩形、圆角矩形、椭圆或直线。
3. 拖动或输入毫米调整位置和尺寸，编辑旋转、透明度、层级、颜色和文字属性。
4. 保存工程，或另存副本。再次打开保持所有图层可编辑。
5. 从模板选择已保存工程；也可从模板打开编辑器，将旧底图复制为一个锁定图层。
6. 点击应用后，模板草稿引用该工程的固定版本；保存模板后正常预览、拼版和导出。

编辑器提供图层排序、显示、锁定、复制、删除、多选、对齐、键盘微调、吸附和撤销重做。图片保留原始比例，可翻转和矩形裁切。固定文字支持多行、字体、字号、字重、颜色、对齐、行距和字距。裁切和缩放仅保存参数。

## 数据契约

工程采用版本化 JSON。基本结构：

```json
{
  "schemaVersion": 1,
  "id": "服务端生成的工程标识",
  "revision": 1,
  "name": "培训结业证书",
  "artboard": { "w": 297, "h": 210, "background": "#ffffff" },
  "layers": [],
  "assets": {}
}
```

图层公共字段为 `id/type/name/x/y/w/h/rotation/opacity/visible/locked`。坐标与尺寸统一毫米，旋转使用角度，图层数组从底到顶。图片附加 `assetId/crop/flipX/flipY`，裁切使用原图范围的归一化矩形；文字附加 `text/fontFamily/fontSize/bold/color/align/lineHeight/letterSpacing`，字号及字距使用 pt；形状附加 `fill/stroke/strokeWidth/radius`，描边和圆角使用毫米。

素材存原始 PNG/JPEG 字节，使用内容摘要标识去重。素材描述记录受控相对路径、格式、原始宽高和显示名称，不能信任渲染进程提供的文件路径。导入校验真实图片内容、尺寸和字节上限。工程限制图层数、画布尺寸、文本长度及数值范围，拒绝非法路径、非有限数值、不支持的版本或缺失素材。

模板新增 `backgroundDesign: { id, revision }`。同一模板只能使用工程底图或旧单图底图其中一种。不自动迁移现有用户模板；用户主动编辑旧底图时，复制原始素材，避免旧单图的立即删除行为损坏新工程。

工程最新版本与历史版本分别管理，已提交版本不可原地改写。保存旧版本需明确另存或基于当前版本更新，避免并发覆盖。素材先完整落盘，再提交工程，最后更新当前版本索引。失败保持旧版本可读。模板只引用存在且已完整保存的版本。

### 素材与版本文件的保留策略

删除工程只移除索引条目，**不删除** `designs/<id>/<rev>.json` 与 `design-assets/<hash>.*`——
未保存草稿（渲染进程 localStorage）与撤销历史仍按引用读取它们，删文件会直接把草稿变成破图。

代价是磁盘只增不减：反复「新建底图 → 加图 → 删工程」会持续占用空间，且当前没有自动回收入口。
缓解措施是素材按内容 sha256 去重（`importBuffer` 命中同一 hash 时复用已落盘文件），
所以重新导入同一张图不会重复占空间。手工回收时须**先关闭应用**，并确认没有未保存的底图草稿。

### 并发与锁

`saveDesign` / `deleteDesign` 经 `designs.write.lock`（目录）串行化。锁的回收判据：
持有者 PID 已消失、锁创建时间早于本次开机、或锁已超过 1 小时 TTL（PID 复用兜底）。
锁位置出现普通文件时直接清除——本模块的锁一律是目录，文件永远轮不到我们释放。
锁清理失败不得顶掉保存本身的真实结果。

## 渲染与清晰度

采用 HTML 文字和 SVG 基础形状，图片引用原始素材。共享模块输出同一套结构和样式；编辑器缩放只作用于外层视口，PDF 使用真实毫米。选中框、拖动手柄和参考线独立覆盖，不能增加内容盒的 border 或 padding。

打印同一大图多次时将素材 URL 放入共享样式，避免几百页 HTML 反复写入同一份 base64。静态文字所用字体与变量字段一起收集和内联。图片裁切、旋转、透明度的 PDF 行为需通过实际输出核对，不将 PNG 无损编码等同于全部图像处理无损。

工程尺寸对应成品：单页为整页、多联为一格、对折为半页。应用时校验工程与成品尺寸，尺寸不一致要让用户明确调整，不能静默拉伸。字体、行高、文本宽度与换行规则在所有入口一致。

有效 DPI 按每张图片的原始像素、裁切区域和物理摆放尺寸计算。文字和形状不受所谓画布 DPI 限制。大图或过多图层超出预算时给出明确错误，不静默缩小原图。

## 撤销 草稿与素材生命周期

一次拖动、一次批量修改或一次属性确认记为一步撤销，选择与视口缩放不进入历史。历史只保存图层参数和素材 ID，限制步数，避免复制大图。

删除图层只取消引用，不立即删除原文件。已保存工程、模板固定版本、草稿和撤销历史可能继续使用素材。第一版对素材采取保守保留策略，不做无法证明安全的自动回收；可审计的素材清理另行实现。

未保存编辑在本地保留恢复草稿，切换页面保持编辑状态。保存期间捕获提交快照；保存完成后仅该快照算已保存，期间的新编辑仍应保留。删除被模板引用的工程必须拒绝并列出引用者。字体删除检查扩展到工程文字图层和历史版本。

## 旧功能兼容

旧单图路径继续原字节内联。底图工程不进入现有字段撤销快照。变量字段的百分比锚点、字号及定位规则维持既有契约。历史出片继续自包含素材和字体，后续编辑工程不改变已归档内容。

新能力遵守 API 不依赖 Electron、IPC 只传纯对象、路径守卫、失败留痕等既有不变量。画布辅助框不改变文字尺寸，导出不通过截图或预览缩略图重编码底图。

## 第二阶段开发计划

### 图层分组

支持一层分组，组内图层保留各自的毫米坐标和图层属性。组合、解组、命名、整组选择、移动、显隐、锁定、复制、删除及顺序调整均进入同一套撤销历史。组成员在图层栈中保持连续，组合时保留成员之间的相对层级。图层列表仍可选中成员修改文字、颜色等属性。

分组关系保存为 `groups: [{ id, name, layerIds }]`。同一图层至多属于一个组，拒绝悬空成员、重复成员和非法顺序。复制组同时生成新的组与图层标识。移动组内成员时，组选择必须一致；被锁定的成员不能因多选或组操作绕过保护。整组缩放、整组旋转与嵌套分组留待后续定义变换规则。

### 参考线

新增水平和垂直参考线，支持输入毫米位置、修改、删除与显示开关。参考线随工程版本保存，拖动图层时可吸附。参考线覆盖在编辑视图上，其显隐与位置不进入 PDF 或 PNG 内容。

参考线保存为 `guides: [{ id, axis, position }]`，`axis: x` 表示固定横坐标的垂直线，`axis: y` 表示固定纵坐标的水平线。位置必须是有限数值且在 ±10000 mm 以内；修改画布尺寸后保留画布外参考线，并在列表提示。最多 100 条参考线、150 个图层组。带分组或参考线的工程使用格式版本 2；旧版工程保持可读，旧程序读取新格式时明确提示版本不支持。

### PNG 导出

可导出当前工程草稿，提供 150、300、600 DPI，默认 300 DPI，以及透明背景选项。界面显示最终像素尺寸：`round(毫米 × DPI ÷ 25.4)`。透明选项控制画布背景；各图层自身的填充和透明度仍遵循编辑参数。

导出使用共享图层渲染器、原始素材和实际字体，独立渲染到目标分辨率，等待资源完成后编码为无损 PNG。PNG 是另行交付的栅格文件；工程继续保存原图，PDF 继续使用原素材、文字与矢量形状。超过像素或边长预算时明确提示，不自动降低分辨率。取消保存不写入文件；失败不覆盖已有成品。

`design:exportPng` 由领域注册表声明，尺寸、素材和字体校验由共享领域代码负责。Electron 渲染能力通过上下文注入，领域 API 继续可在纯 Node 中加载。接口允许显式目标路径以跳过保存对话框；纯 Node CLI 与现有 PDF 出口一致，缺少 Electron 渲染能力时返回 `GUI_REQUIRED`，本阶段不增加后台渲染进程。

### 第二阶段验收

- 分组后移动保持成员相对位置；一次撤销恢复整次操作；复制、解组、删除后成员索引与标识正确，锁定成员受保护。
- 工程保存重开及草稿恢复保留组和参考线；旧模板固定版本照常预览、打印。
- 实际拖动吸附参考线，隐藏线后按界面约定停止吸附；输出文件没有辅助线和选中框。
- 实际 PNG 的宽高与指定 DPI 完全对应；透明区域 alpha 正确，图层内容有实际像素，中文和图片加载完成；Windows 显示缩放不改变导出尺寸。
- 导出不更改工程版本、素材原件或 PDF 保真行为；失败和取消路径有验证。
- 通过领域、真实 Electron 界面、PNG/PDF 和打包产物验证后交付本地安装包。
