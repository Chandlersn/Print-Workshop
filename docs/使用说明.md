# 批印坊 · 使用说明

这份说明按实际制作顺序介绍：导入名单和照片，制作批量样板，修正个别照片，设计版面，检查并输出。只做文字证书时，可以跳过照片处理。

## 一、安装与数据准备

从 [GitHub Releases](https://github.com/Chandlersn/Print-Workshop/releases/latest) 下载 Windows 64 位桌面包。安装版按提示安装；免安装目录可直接运行其中的应用。安装包当前未签名，请核对下载来源及 Release 附带的校验和。

完整桌面包包含本地人像抠图和人物对齐模型，不需要申请密钥或上传照片，也不要求独立显卡。制作、模型处理和输出可离线使用；版本检查和更新下载需要联网。模型首次使用时会加载，整批处理时间取决于照片大小和电脑性能。

数据默认保存在 `%APPDATA%\printpress\data`。应用底部「更改…」可迁移数据目录。备份时复制整个目录；如果单独设置了 `PRINTPRESS_ASSET_DIR`，素材目录也要一起备份。

## 二、先跑通一批

1. 在「数据」页导入 Excel 或 CSV，打开需要打印的列；如果使用照片，再打开一列「配图」。
2. 在「变量照片」页导入照片文件夹，检查匹配结果，选择一张样板设置效果并应用到全部照片。
3. 在「底图制作」做固定版面，添加变量照片框；再到「模板」页放置姓名等字段，保存模板。
4. 在「变量照片」打开批量检查，查看处理后及套用模板的效果，单独修正少数特殊照片。
5. 在「打印中心」选择模板和人员范围，确认预检及预览，再导出 PDF、逐条图片或直接打印。

第一次可以先使用应用自带的示例名单和模板，确认流程后再导入正式数据。

## 三、名单与照片怎么关联

### 导入和选择列

Excel 支持 `.xlsx`、`.xls`，CSV 支持自动识别常见 UTF-8 / GBK 编码。第一行作为表头；多工作表文件可按表分别导入或合并。

列头的「印」控制该列是否可作为模板文字字段；「配图」控制照片匹配。每份名单最多启用一列配图，姓名、编号或单独的照片文件名列都可以。两个开关相互独立。

打开「变量照片」时，页面跟随数据页当前名单。多份名单都开了配图时，先在数据页打开需要处理的那份，再进入变量照片页。

### 导入照片

选择照片文件夹并确认预检结果。支持 PNG、JPG、JPEG；例如名单中的 `张三` 可匹配 `张三.jpg`，`1001` 可匹配 `1001.png`，也可以填写 `部门/1001.jpg`。

匹配忽略大小写和常见图片扩展名差异，保留子目录区别。同名有多张照片时会报告冲突，不会自行选一张。只有有效、唯一匹配的照片才入库；未匹配文件、同名冲突和坏图会被跳过并给出原因。

默认「补充缺失照片」保留已有有效照片；同名但内容不同的文件不会替换旧图。需要整份更换时，使用「替换当前名单照片」。这会更新当前名单的关联清单，已入库原件仍保留。

变量照片及处理结果存放在数据目录的 `photo-assets` 中，与普通图层素材分开。旧版共用的照片会在后台复制到新目录；旧文件保留，以免影响其他工程和历史数据。

在照片关联表中勾选照片，可跨页选择或选择当前筛选结果，再点击「删除已选」；也可以点击「删除全部已导入照片」。删除后可重新导入：名单中的文字和外部文件夹原件不会删除；多人共用同一照片时，这些人员都会失去该照片；其他名单或普通图层仍引用的文件会保留。对应的单张处理及取景设置会清除。

单张照片不得超过 64 MiB，匹配照片合计不得超过 2 GiB，超过时请拆分导入。入库后移动外部文件夹不会影响已导入照片。

新名单首次导入后，系统会以名单中第一张成功匹配的照片为基准，自动统一照片像素尺寸，并使用本地人脸模型统一脸部大小、水平居中和眼睛高度。尺寸沿用首张照片，最长边限制为 3200 像素，极小的照片会放大以满足最低尺寸；原始照片不受修改。首次处理完成前请等待，失败时可在变量照片页重试。不会自动抠图，需在样板设置中自行开启。

如果首张照片没有识别出单个人脸或本地模型不可用，系统只统一画布尺寸并等比居中，不会猜测人物位置。首张识别成功时，其他照片无人脸或有多人会回退到等比居中，并在批量检查中提示；请查看实际效果并按需单张修正。自动居中依据人脸，不保证身体轮廓、姿态完全一致。

修改配图列或照片名称后会重新匹配；新匹配到的是此前未入库文件时，仍需重新导入。表格可以筛选问题、搜索、分页，并点击行号定位原记录。

## 四、制作智能批量样板

在「变量照片」点击「制作样板」，选择一张有代表性的照片。左侧对照原图和处理效果，右侧设置规则。

| 设置 | 用途 |
| --- | --- |
| 统一宽高 | 确定输出像素尺寸；「使用这张照片的尺寸」可按样板取尺寸，最长边适当限制以控制处理量 |
| 等比完整显示 / 等比铺满裁切 | 选择保留整张照片或铺满画幅，避免直接拉伸人物 |
| 人像自动抠图 | 使用本地 MODNet 模型去除背景，保留透明通道 |
| 按可见主体适配 | 忽略透明空白，根据可见主体确定适配范围 |
| 人物大小与眼睛高度对齐 | 使用本地 YuNet 模型统一脸部大小、水平位置和眼睛高度 |
| 主体缩放、水平与垂直位置 | 在统一规则上继续调整取景 |
| 底部渐隐 | 设置从哪里开始变透明，以及底部保留多少不透明度 |
| 四周羽化 | 对照片外框或可见主体轮廓柔化边缘，并设置范围与边缘不透明度 |

人物对齐中的「脸部高度」指模型检测到的脸部区域，不是包含头发的完整头部尺寸。它调整大小和位置，不自动摆正歪头；未识别人脸或检测到多人时，保留普通适配并标记检查，不会擅自挑一个人。

底部渐隐和羽化可以叠加。例如保持主体中心不透明，只让底部逐渐消失，或让轮廓边缘约为 50% 不透明。原图本来透明的区域不会凭空变成不透明。

调整后会生成预览。确认效果后，点击「应用到全部 N 张照片」。同一张原图被多人使用时，共用批量计算结果；每张不同原图仍各自计算蒙版。应用期间可查看进度并取消，取消在当前照片处理完成后生效。

整批失败或取消时，之前已应用的规则和结果继续有效，不会发布半批新效果。重新应用会复用相同规则下已完成的计算。处理失败、照片更换后尚未处理或结果文件损坏时，请修复后再输出。

## 五、复用样板与自动沿用

### 保存和载入规则

在样板设置中填写名称，点「另存样板」。以后在另一份名单打开样板下拉框，选中这份规则，检查预览后再应用。

保存模板时，会把当前名单已应用的照片规则一并保存；样板下拉框中会出现「模板 · 名称」条目。它保存规则，不包含整份名单和人员照片。选择模板或载入规则不会自动覆盖当前照片，仍需在变量照片页确认应用。

删除命名样板只删除保存的规则，不改变已经处理好的照片。模板条目在这里只读，需要到模板页管理。

### 新照片自动接着处理

首次自动统一后，「新增或更换照片后自动沿用已应用样板」默认开启。此后导入新照片、替换照片或修改名单使照片重新匹配时，会检查变化项，只处理需要更新的照片；已有有效结果继续复用。既有名单的原有设置不会被首次导入规则覆盖，也可以手动开启或关闭此开关。

开启开关时也会检查已有待处理照片。关闭应用会停止当前运行，下次启动会重新检查待处理项。界面显示自动处理进度和失败原因；失败后可重新应用样板，成功算出的缓存仍可复用。

自动沿用使用的是已经应用的规则，右侧尚未应用的预览调整不会偷偷变成整批规则。关闭开关后，新增照片需要手动应用；原先已处理好的照片仍保持当前效果。

## 六、检查整批效果和单独修图

### 批量检查

在变量照片页打开「批量效果检查」。可以搜索姓名、照片名或行号，并筛选有提示、待处理或已单独修改的记录。每页最多显示 24 条。

- **原始照片**：确认源照片是否对应正确人员。
- **处理后**：检查抠图、人物大小、透明边缘和渐隐。
- **套用底图与模板**：选择当前名单的模板，查看照片、底图与文字实际组合。此预览复用打印排版。

提示包括缺图、同名冲突、处理未完成、旧单张修改因换图停用、人脸未识别、多人、裁切风险和低清晰度。选模板后，清晰度会结合实际输出尺寸检查；低于 150 dpi 时建议换清晰照片。视觉提示需要人工判断，不代表已自动发现所有画面问题。

### 只修改某个人

点击某张照片或「单张编辑」，打开该人员的编辑面板。它复用样板设置，但「仅应用此人的设置」只影响当前人员。

开启人像自动抠图后，可以选择快速模式或精细模式。样板预览和新建单张修改默认使用精细模式，整批默认使用快速模式；已保存的单张修改会保留原来的模式和结果。参考本机试验，快速模式约每张 1～4 秒，精细模式约每张 10～16 秒，实际时间随电脑和照片变化。精细模式首次加载也需要额外时间；如果模型缺失，可切换快速模式或安装完整安装包。

样板预览与批量处理可以分别选择模式。两者不同时，样板的抠图边缘可能与批量结果不同，可切换样板预览模式进行对照。批量检查中可以对需要修整的人单独使用精细模式，确认后只保存到该人员；批量自动沿用使用已应用的批量模式。

当衣服和背景颜色相近，自动抠图误删主体时，点击「自由拉索 · 圈定人物并抠图」，在原始照片上沿整个人物外围大致画一圈，给头发、手脚和衣服留一点余量，松开后点「按人物范围抠图」。系统把这个范围作为模型识别的人物线索，范围内的背景仍会被处理，轮廓附近也保留一定识别余量。请检查人物是否完整；如模型仍有遗漏，可使用图片编辑中的「恢复主体」修补。

确认预览后点击「仅应用此人的设置」，圈选范围只属于当前人员和当前原图，不会套用给其他人。重新抠图会替换此前的手工修补；换原图后旧范围不再生效。旧版已保存的圈内保留效果继续保留，重新圈选后使用新的模型识别方式。

可以单独调整尺寸、抠图、人物对齐、位置和柔边，也可以点击「图片编辑 · 抠图边缘修补」进入共用图片编辑器：

| 工具 | 用法 |
| --- | --- |
| 精细擦除 | 涂抹后变透明，用于清理抠图残留；可调整画笔直径和柔边 |
| 恢复主体 | 从同位置、同取景的原色图恢复误删内容；恢复范围可能包含原背景，请按需涂抹 |
| 裁剪 | 拖框或输入像素坐标确定保留范围 |
| 仿制图章 | 先点击源位置，再在目标位置涂抹复制；可以重选源点 |
| 魔法擦除 / 矩形修补 | 参考附近内容修补背景，适合去掉污点或杂物 |

可以放大精修，点击撤销图标或按 Ctrl+Z 撤回上一笔；点「完成」保存当前人员的修改，点「取消」放弃本次编辑。照片原件保留完整。

从底图制作的「魔法擦除」打开图片时，不透明图片默认使用周围画面修补；图片含透明区域或原有透明擦除时，默认切换为「精细擦除」。两种方式可手动切换；只有提供对应原色图时才显示「恢复主体」。

单张修改按稳定的人员记录保存。即使多人共用同一张原图，也不会一起改变；重新应用整批样板会保留这些单张例外。点击「恢复统一样板」取消该人员的特殊处理。

重新应用单张参数会按参数重新生成图片，替换之前的手工修补；要接着修补，应打开图片编辑器。原照片或配图列更换后，旧修改会停用，防止套错人，请重新检查并调整。

「恢复全部原始照片」会关闭当前整批处理和自动沿用，并清除这份名单的单张处理结果。

## 七、底图排版与参考样图

在「底图制作」添加固定图片、文字或形状，添加「变量图」作为名单照片的输出位置。变量框可以调整毫米尺寸、位置、取景和图层效果。

选中变量框点击「编辑参考样图」，会在当前工程中生成一张普通图片。它使用现有裁剪、擦除、图章、颜色、翻转、透明度、分组和图层工具，始终只在编辑器显示，不会打印。

| 编辑对象 | 对实际成品的影响 |
| --- | --- |
| 变量照片页的统一样板 | 影响整批使用统一规则的照片 |
| 变量照片页的单张编辑 | 只影响该人员的照片 |
| 底图中的参考样图 | 只供排版参考，不改变人员照片和批量规则 |
| 底图中的变量框 | 决定真实输出的位置、尺寸、取景和框效果 |

编辑参考图不会同步改变变量框。需要调整实际输出位置时，点「选择变量框（调整实际输出位置）」。隐藏或删除参考图即可查看真实变量照片；「重新取样」会按当前样板重新生成参考图并重置参考修改，可撤销。

保存工程会保留参考图及修改。含可打印变量图的工程应应用到模板，再从打印中心输出；静态底图导出不负责逐人换图。

图层、PSD / PSB 导入、文字颜色拾取、工程包和高清底图导出等操作见[底图制作使用说明](底图制作使用说明.md)。

## 八、模板与批量输出

### 保存模板

在「模板」页选择名单和底图工程，把姓名、编号等字段放到合适的位置。只有数据页打开「印」的列才会进入字段面板。底图工程的尺寸应与成品尺寸一致；多联模板中使用的是单个成品尺寸。

选中字段后，可在属性栏选择横排或从上到下竖排，并设置竖排文字朝上、朝左或朝右。拖动选中框右下角可调整框的宽高，字号也会随之变化；也可直接输入字号。文本不会因框变小而自动裁切，不同记录文字长短不同时，请结合打印预检和预览检查是否超出纸面。切换排列方向会恢复按文字内容确定的框大小，方便重新调整。

模板使用已应用的固定工程版本。底图另存新版后，需要重新应用，或从模板进入底图编辑后「保存并应用到模板」。仅保存底图不会自动替换所有模板。

### 输出前检查

在「打印中心」选择模板，确认绑定名单和本次人员范围。可搜索并勾选少数人员补打，也可选择全部。

预览某张海报时，点击「编辑此人底图」即可回到底图制作；一页有多位人员时，先在预览栏选择人员。编辑器打开该人员的独立副本，展示该人员照片和名单字段参考；名单字段本身仍在模板页调整。完成后点击「保存并应用到此人」，返回打印中心检查。该修改只作用于该人员，批量输出和归档也会使用对应副本，其他人员仍使用原模板。可在预览栏点击「恢复此人默认底图」撤销这一单人底图。若共用模板的底图或成品尺寸后来变化，系统会提示先重新检查或恢复该单人底图，避免误用旧版。

预检会区分缺图、空值、同名冲突、名称无效、照片损坏和未完成处理。缺图或空值按现有规则留白；冲突、损坏、无效或未完成处理需要先解决。清晰度、未识别人脸、多人和裁切提示可展开查看，点击行号定位记录。

先逐页预览，再输出。预览栏的缩放可选 25%、50%、75%、100% 或 125%；这只改变屏幕上的预览大小，不影响导出和打印尺寸。人物边缘、文字溢出和字体变化仍应人工确认；正式批量打印前建议试打一页。

### 输出方式

- **PDF**：整批生成，适合归档、交付和换设备打印。
- **逐条图片**：按人员导出 PNG、JPG 或 WebP，可设置文件名字段、分辨率及适用格式的质量。
- **直接打印**：在系统打印对话框选择设备；缩放使用「100% / 实际大小」，关闭页眉页脚。

展开打印中心的「出片设置」，可调整分辨率、图片格式、质量和图片文件名字段；折叠时仍会显示当前使用的设置。

提高输出 DPI 不能补回低清原图的细节。PNG 和 JPG 可记录所选 DPI；WebP 按所选 DPI 计算像素尺寸，但不写 DPI 元数据。

照片输出默认按实际需要降采样，保留原件。开启样板处理时，成品使用处理后的照片；归档保存该次使用的照片及任务快照。迁移单次任务时应复制整个任务目录。

在打印中心的海报预览中点击或直接拖动某人的变量照片，选中后会显示图片框。拖动照片可移动，拖动图片框四周的控制点可调整大小；方向键微调位置，按住 Shift 可加快移动。调整后自动保存，同时用于预览和出片，只影响此人当前模板的照片图层；基础调整不会生成单人底图工程。「恢复默认」可撤销该人的单独调整。变量照片页的单张编辑是照片处理结果，两者可叠加使用。回到底图编辑该人员时，已保存的位置和大小会带入单人底图。

需要修整人物抠图时，点击预览栏的「精修此人照片」，即可打开变量照片页中该人员的单张编辑，使用抠图模式、自由拉索和边缘修补工具。多联预览可先选择人员或点击对应照片。确认后点击「仅应用此人的设置」，再点击「返回打印预览」检查结果；原先保存的照片位置和大小继续生效，其他人员不受影响。

从打印中心「编辑此人底图」保存的工程归入底图制作页的「单人海报工程」，与「批量底图工程」分开显示；新建的单人工程版本保存在独立目录，不进入批量模板的底图选择列表。单人工程可在列表中打开查看；如需将修改应用到海报，请从打印中心选中对应人员再进入编辑，也可在此选择该人员已保存的工程。恢复该人员的默认底图后，可在单人海报工程列表中删除不再使用的工程；旧版本的工程文件会保留在原目录，仍按单人海报分类。

## 九、记录、更新与备份

成功全量输出会更新名单累计打印状态；部分补打只记录本次任务。打印历史可以查看快照、重打，也可以勾选多条批量删除。

删除历史会删除对应任务记录和归档副本，不删除已导出的 PDF、照片原件、名单或模板，也不回退名单累计的「已打」状态。

启动后会检查已发布版本，发现新版本时后台下载并显示进度。保存编辑内容后点击「立即重启安装」升级；离线或更新失败时可在「关于」重试或前往发布页。更新不会要求上传制作数据。

迁移整套资料时备份完整数据目录。`.ppdesign` 工程包用于底图工程及素材的转移，不能代替完整名单和照片备份。

「关于 → 清理缓存与残留」可回收浏览器缓存、已删除工程残留和出片照片派生件。派生件是按输出分辨率生成的临时图片，删除后可重新生成，不删除照片原件；正在输出时不会清理它们。被系统占用的缓存会提示保留或排到下次启动处理。

## 十、常见问题

**开了自动处理，为什么新照片还没变化？** 先确认已应用样板且当前名单开着配图，再查看自动任务是否仍在运行或失败。同名不同内容在「补充」模式下会保留旧图，需要替换时使用替换入口。

**底图里明明擦过照片，打印为什么没变？** 底图中编辑的是排版参考样图。要修改实际人员照片，请到变量照片页的单张编辑；要整批处理，请应用样板。

**一寸照怎样一页排多张？** 在模板页选择多联版式，设置单张成品尺寸、行列和间距，预览后按需开启裁切线。

**PSD 字体为什么不完全一样？** PSD 通常记录字体名称，不包含可直接使用的完整字体文件。本机缺字体或特殊效果不能完整转换时，请按导入报告补字体、替换字体或使用文字栅格图层。iFonts 等外部字体软件的同步尚未接入。

**怎么恢复单个人或整批照片？** 单张编辑使用「恢复统一样板」；样板面板使用「恢复全部原始照片」，后者也会清除当前名单的单张修改。

**抠图或人物对齐需要联网吗？** 完整包中的模型在本机运行。若提示组件缺失，请安装包含模型的完整桌面包。

**如何用脚本操作？** `node bin/pp.cjs ops` 可查看操作清单，`node bin/pp.cjs --help` 查看命令用法。独立 CLI 写操作需要显式授权；桌面窗口占用数据目录时，CLI 保持只读。
