# 批印坊 · 使用说明

> 给第一次拿到批印坊的你。从安装到打出第一批证书，大约十分钟。

## 一、安装

**系统要求**：Windows 10 / 11（64 位）。

**获取方式**：到 [GitHub Releases](https://github.com/Chandlersn/Print-Workshop/releases/latest) 下载最新安装包（`PrintPress-x.x.x-Setup.exe`）。两种形态任选：

- **安装版**（推荐）：双击安装包，按提示安装（可选安装位置，自动创建桌面和开始菜单快捷方式）；
- **免安装版**：解压后直接双击 `批印坊.exe`，不写注册表，删掉文件夹即卸载。

### 首次安装提示「Windows 已保护你的电脑」怎么办？

因为安装包没有购买代码签名证书，Windows SmartScreen 会对陌生程序出手，这是正常现象，**应用本身没有任何联网上传行为**。应对方法：

1. 在蓝色警告窗口点「更多信息」；
2. 出现「仍要运行」按钮，点击即可继续安装。

部分杀毒软件可能对免安装版报「未知程序」，加入信任列表即可。

### 数据在哪里？

所有数据（名单、模板、底图工程及素材、字体、打印记录）默认存在本机 `%APPDATA%\printpress\data`，**不上传任何服务器**。想放到 D 盘或网盘同步目录，打开应用后在底部「更改…」选择新位置即可，现有数据会自动迁移。备份或迁移时复制整个 data 文件夹。

## 二、四步打出第一批

首次启动自带 **7 套示例模板**（证书文书 3 套 + 拼版小件 4 套）、示例名单，以及「底图制作」里 1 套排好位置的身份证参考版面，可以直接体验，也可以按下面四步用你自己的数据走一遍：

1. **导入名单**：打开「数据」页 → 点「导入」→ 选 Excel（.xlsx/.xls）或 CSV 文件。第一行会被当作表头，UTF-8 / GBK 编码自动识别。Excel 里有多个工作表时，可以选择每张表拆成独立数据集，或合并成一张。
2. **制作底图**（可选）：打开「底图制作」，把证书底图、固定文字与边框分别做成图层；直接用一张整图当底图也行，可跳过这步。
3. **设计模板**：打开「模板」页，上传一张证书底图（PNG/JPEG）或选用刚做好的图层工程；再选择数据集、把要打印的字段摆到画布上 → 保存。
4. **批量出片**：打开「打印中心」→ 选模板（自动带出绑定名单）→ 预览确认 → 导出 PDF 或直接送打印机。

## 三、数据页：名单管理

### 变量照片库与人像出片（v0.6 预览）

先在数据页点击列头的「配图」开关，位置与「印」并列。**每份名单最多启用一列**：可以选择姓名、编号或照片文件名；改选其他列会自动关闭原来的选择，再次点击已启用列则关闭配图。选择自动保存，且不影响「印」。然后打开顶栏「变量照片」，页面自动跟随数据页当前打开的名单和配图列，只需点「选择照片文件夹」，无需再次选择关联名单。返回数据页切换名单后，照片库随之切换；当前名单关闭配图时会提示先开启。尚未选择名单且只有一份开启配图时自动识别，多份时先在数据页打开要使用的名单。照片导入和检查统一在「变量照片」页操作，数据页仅保留列头配图开关。支持 PNG、JPG、JPEG，原件不压缩；原目录移动后不影响已导入照片。

导入前系统按当前「配图」列筛选，只有唯一匹配且可读取的照片才复制入库；未匹配、同名冲突和坏图跳过，并显示入库数量、跳过数量及具体原因。系统自动关联：姓名“张三”对应 `张三.jpg`，编号“1001”对应 `1001.png`。匹配成功的照片自动收纳到系统，直接在名单表格逐行显示配图列的值、照片和匹配结果，缺图显示空位；不再重复显示照片卡片或详情区。可筛选全部记录或待处理记录、分页查看，点击行号回到数据页修改。表格优先显示缩略图；缓存加载失败时自动改用系统原件。切换配图列只复用已入库照片；若新字段匹配的是之前被跳过的文件，需要重新选择照片文件夹导入；自动匹配不会改写姓名、编号或其他名单值。同名多图会报告冲突，不擅自选取。

名单可以填写 `1001`、`1001.jpg`，或者 `部门/1001.jpg`。匹配忽略大小写及 JPG/JPEG/PNG 扩展名差异，保留子目录；同名存在多张图时会报告冲突，不自动挑选。界面分别列出缺图、空值、名称无效、坏图，以及多人共用照片的提醒。点问题行号可回到该单元格补录，修改后重新打开或点「重新检查」。

已有照片时，主按钮「补充缺失照片」只补缺图或损坏绑定：同内容复用原件，同名但内容不同则保留原图并说明原因，目录里没有的旧照片也继续保留。需要整份重建时，使用次级按钮「替换当前名单照片」；它只替换这份名单的关联清单，不删除已经入库的原件。最近导入任务会显示完成、取消或恢复状态。符号链接目录不扫描；超过 64 MiB 的单张照片、匹配照片合计超过 2 GiB 时需拆分后导入。从 alpha.2 升级后，先到数据页启用一个「配图」列；原照片清单仍可复用。

**从照片库到出片：**

1. 在数据页启用一个「配图」列，在「变量照片」导入照片文件夹并确认自动匹配结果。
2. 在「底图制作」点「＋ 变量图」。按钮自动校验模板绑定名单（未从模板进入时使用数据页当前名单）的配图开关，未开启时仅置灰，界面不显示长提醒或悬浮提示；返回编辑器自动刷新，实际插入前再次校验。参考名单只列出已开启配图的数据集并自动选择：从模板进入时使用模板绑定名单，否则使用数据页当前名单；两者均未指定时保留上次有效选择或选第一份已开启的名单。相关名单关闭配图时不会自动改用其他名单来启用按钮。只有一份时无需手选；全部关闭时按钮不可点击。变量图默认 35 × 45 mm，可调整位置、尺寸、填充方式、焦点和圆角。以后切换配图列，变量图会跟随，无需重新制作。
3. 保存工程。在「模板」选择该工程并「应用工程」，绑定同一份名单后保存。工程尺寸须与模板成品尺寸一致；也可以从模板页「制作新底图」进入编辑器，保存并应用。
4. 「打印中心」选择模板，即可预览、导出 PDF 或打印。下拉列表中含变量图的模板会以浅色背景、左侧色条及「变量图」标签突出显示，选中后仍保留标签。支持单页、多联、对折和选行出片。缺图或空值时照片位置留白，该行仍正常出片；关闭配图时所有变量图留白。同名冲突、损坏原件和无效名称仍需处理后出片。

照片列的「印」开关只控制是否作为文字字段显示，不影响变量图读取文件名。模板页显示样例行照片；打印中心按物理纸张逐页预览本次范围，上一页/下一页切换；导出仍包含全部选定记录。变量图所在工程为格式 5，旧版软件无法打开；工程包保存框和绑定关系，人员照片需在目标电脑另行导入。包含可打印变量图时，请通过模板导出 PDF，不能直接作为静态底图导出 PNG。

归档保存 HTML 和同目录 `photos/` 原件，迁移时需复制整个任务目录。alpha.9 已验证两轮 500 张不同大原图导出，采样内存峰值约 1.9 GiB；大原图 PDF 体积仍较大，实际打印机与正式升级验收继续推进，详见 [v0.6.0 开发计划](v0.6.0开发计划.md)。

### 日常操作

- **按「导入批次」管理**：每导入一次文件（含多工作表拆分出的全部数据集）就归为一个批次，侧栏顶部的「导入批次」下拉可以随时切换；删除按钮跟着批次走——多表导入的大文件想清掉，一键「删除整批（N 个工作簿）」即可，不用逐个删。
- **修改内容**：直接点击表格单元格编辑，Enter 提交、Esc 取消；支持加行、删行、翻页，表格字号四档可调。
- **「印」开关**：每个列头有一个单字「印」开关。**只有打开「印」的列，才会出现在模板设计的字段面板里**。没用的列不进设计器，避免干扰。激活过的数据集在侧栏显示「印 N」徽标并自动置顶。
- **「配图」开关**：每个列头有一个「配图」开关，每份名单最多启用一列（完整用法见「变量照片」）。开启配图的名单在侧栏亮出一个「图」字（与「印 N」同一行、同样逻辑），并排在「印 N」名单之前自动置顶；模板页的数据集下拉同样把已配图名单排在最前并标注「（已配图）」——正在走照片流程的名单不用在长列表里翻找。
- **打印状态一目了然**：打印或导出过的数据集整条变淡绿色并带「已打 N」旗标；没打过的保持白纸原样——要找遗漏，看哪条还是白的就行。选中数据集可在详情头看到「已打印 N 次，最近日期」。
- **筛选已打／未打（v0.6 预览）**：侧栏「全部／已打／未打」按当前导入批次筛选名单，可与名称搜索叠加，按钮显示符合条件的数量。「已打」指至少成功全量打印或导出 PDF 一次；失败、取消和部分补打不将整份名单标为已打。筛选后详情跟随可见名单，空结果时不显示旧详情。切换导入批次保留筛选；新导入名单会回到「全部」。删除打印历史不会回退名单的累计已打状态。

## 四、底图制作：把版面做成图层

- **从图层底图开始**：点「新建底图」，设置工程名称、画布宽高和背景色；用左侧工具添加图片、固定文字、矩形、椭圆或直线。姓名、编号等随名单变化的内容仍应在「模板」页添加为字段。
- **本地素材库**：「底图制作」页顶部可打开「素材库」侧栏，把常用图片收进来跨工程复用——按名称/标签搜索、点标签筛选、★收藏、⊘归档（隐藏但**不删原件**）、✎改名改标签，点一张就放进当前画布。同一张图无论用在几个工程，磁盘上都只存一份原件；改库里的名字、归档某张图，都**不会改写已经引用它的旧工程**。工程里粘贴/拖入的图默认是「临时件」，删除图层会连带清理原件；想让它在删图层后仍保留，在图层行上点「＋」加入素材库即可（加入后受保护、不随删图层消失）。「清理未引用」会先列出既不在任何工程、也不在素材库的孤立原件，确认后才删。侧栏的「打开素材库文件夹」可在系统文件管理器里直接查看原件（design-assets/）。
- **编辑图层**：点选画布或左侧图层列表，在右侧用毫米数值精调位置、尺寸、旋转、不透明度、文字和颜色；也可直接拖动和调整尺寸。图片裁切只记录原图区域，不修改原文件。选中图片后属性面板里有「**成品尺寸 / 比例**」下拉：选 1 寸（25×35mm）、2 寸这类毫米规格会同时把框设成该成品尺寸**并把裁切调成同一长宽比**；选 1:1 / 3:4 / 9:16 这类纯比例则保持当前宽度、只改高度——两者都只动这一张图，不会把脸拉长。同一面板里还有**描边（衬边）**与**投影**：描边画在框的内侧、不改变成品的毫米尺寸（证件照白边用这个），投影跟着图片的实际轮廓走（抠过底的 PNG 只投轮廓，不会投出一个方盒）。图层列表上方的项目会盖住下方项目，可调整顺序、显隐、锁定、复制或删除。
- **线性渐变与外阴影（v0.5.0）**：在「底图制作」右侧「工程与画布」中，「画布背景」下方的「使用线性渐变」可为整张画布设置渐变；选中矩形或椭圆后，向下滚动右侧属性栏，在「填充颜色」下方可为图形设置线性渐变，并在其下方开启「使用外阴影」。渐变可调整方向、2～8 个色标的颜色、位置和透明度；阴影可调整水平/垂直偏移、模糊、颜色与透明度。
- **混合模式、图片调色与组透明度（v0.7）**：选中任意图层后，属性栏「不透明度」下方出现「混合模式」——提供正常、正片叠底、滤色、叠加、变暗、变亮、颜色减淡、颜色加深、强光、柔光、差值、排除、色相、饱和度、颜色、明度共 16 种。这里**只收录画布、打印与 PDF 表现完全一致的模式**：Photoshop 里那些本应用不提供的模式不会出现在列表里，避免「预览好看、成品变样」。选中图片图层（含变量图）时属性栏还会出现「颜色调整」：亮度、对比度、饱和度、去色、反相五根滑杆，每根旁显示当前百分比（亮度一类 100% 是原样，去色/反相 0% 是原样、100% 拉满），拖动即时预览、松手只记一步撤销，「恢复原始颜色」一键还原。选中分组时属性栏多出「组透明度」，它会**乘算到组内每一个图层**（与该图层自身的不透明度叠加）。以上效果在画布、打印、PDF 与 PNG 导出中同源同效；没有调整过的工程，渲染结果与升级前完全一致。
- **多选、分组与撤销**：按 Ctrl 或 Shift 点击图层可多选；方向键微调 0.1 mm，Shift 加速；拖动时可吸附，按住 Alt 暂时关闭吸附。至少选择两个图层后可组合，组可整体移动与对齐；当前支持一层分组。Ctrl+Z 撤销，Ctrl+Shift+Z 重做，Ctrl+S 保存。
- **工程版本与模板引用**：点击「保存工程」保存一个新版本；「另存副本」用来制作相似底图。模板会固定引用应用时的底图版本，之后保存工程的新版本不会自动改变模板。可在模板页选择新版本并应用，或从模板进入「编辑底图」，完成后点「保存并应用到模板」。工程尺寸不匹配时，先调整画布尺寸再应用；采用模板尺寸不会自动缩放现有图层。
- **从旧图片底图转换**：已有模板可以点击「将底图转为图层编辑」，把当前图片作为图片图层继续添加文字和形状。图片里已经合成的文字或边框不会自动拆成单独图层。
- **清晰度与图片导出（v0.7 支持 PNG / JPEG / WebP）**：图层工程保留导入 PNG/JPEG 的原始文件内容，变换以参数记录；选中图片可查看按实际尺寸计算的有效 DPI。点「导出图片」后：**图片格式**可选 PNG、JPEG 或 WebP；**输出分辨率**可选 150、300 或 600 DPI；**透明背景**会去掉画布底色（图层中的白色矩形仍会输出）。选 JPEG 或 WebP 时多出**图片质量**滑杆（JPEG 默认 90、WebP 默认 80，切换格式会回到该格式的默认值），下方显示**约**多少体积的估算；导出完成条上给出真实文件大小。三点必须知道：**JPEG 没有透明通道**，勾了透明会改铺画布自己的底色并在对话框提示（否则会静默丢掉透明层）；**WebP 文件里不会写入 DPI**，要按物理尺寸打印请选 PNG 或 JPEG；**PNG 是无损的**，体积由内容复杂度决定，因此不给估算。提高 DPI 不会增加低分辨率原图的细节；导出使用当前编辑稿，不会保存新工程版本。
- **标尺、布局网格与参考线（v0.7）**：右侧「标尺 / 网格 / 参考线」面板里，**标尺**与**布局网格**都可开关（默认关，不打扰只想摆图层的人）。打开标尺后画布上方与左侧出现毫米刻度，刻度疏密随缩放自适应；**从上方标尺往下拖、或从左侧标尺往右拖，就能直接拉出一条参考线**，松手才落库（拖一次只记一步撤销，不会把几十帧中间态灌进撤销栈）。布局网格可设**间距**与**细分数**（默认 10 mm 分 5 格），卡片排版时照着它对位置。面板里还有**吸附目标**四个独立开关：画布边缘与中线 / 参考线 / 网格主格线 / 图层边缘与中心——想只按参考线对齐，就把其余三类关掉，免得图层「到处乱吸」；网格吸附只吸主格线，不吸细分的次格线。拖动图层时按住 Alt 可临时关闭全部吸附。参考线、标尺与网格都**不会输出**到 PDF 或导出的图片。
- **换电脑继续编辑（工程包）**：点「导出工程包」把工程**已保存的那一版**连图片原件与上传字体打包成一个 `.ppdesign` 文件（导出的是版本文件，不是当前未保存的修改——有未保存改动时会让你选「保存后导出」还是「导出已保存版本」）。在另一台电脑上点「导入工程包」：先看到检查结果（尺寸、图层数、图片与字体数量、解压体积），确认后**导入为一份新副本**（新工程、第 1 版），不会覆盖已有工程，也不会改动当前画板；想直接打开就点「导入并打开」。若包里用到的字体本机没有，界面会逐条让你选择：用默认字体、替代为本机已有字体，或指定一个字体文件。系统字体不会打包（也没法打包），换机后若字形不同，按提示补字体即可。
- **完整操作说明**：图层属性、分组、参考线、草稿恢复和 PNG 限制见[底图制作使用说明](底图制作使用说明.md)。

## 五、模板工坊：版式设计

- **底图与纸张**：单张图片底图支持点画布中央上传、拖入图片文件，或按 Ctrl+V 粘贴剪贴板截图。也可以在顶部打开「底图制作」，把图片、固定文字与形状分别编辑。纸张可选 A3/A4/A5/B5/A6 预设或输入自定义毫米尺寸；模板采用多联或对折版式时，底图尺寸需要与单个成品或半页成品相符。
- **字体**：模板页「字体管理」可上传 TTF/OTF 字体。底图工程使用的上传字体在被工程或模板引用时受到删除保护；换电脑时应备份整个 data 文件夹。
- **保存有校验**：模板字段和所选数据集激活列必须匹配；字段失效或数据集未绑定时，模板保存或打印会提示处理。
- **多联拼版（打小件必看）**：打证件照、胸卡、桌牌这类小成品时，把版式从「单张」切到「多联」，填一下成品尺寸（内置 1 寸 / 2 寸 / 5 寸等常见规格，也可自由填毫米），系统自动算出每页能排几列几行并在纸上居中；画布随即切换成「单个成品」来设计，可以打开裁切线方便手工裁。工具栏里「纸张」和「成品」是两个独立维度——整张大纸和单个成品各自选预设或填毫米，自由组合。
- **对折桌牌（台签）**：版式切到「对折桌牌」后，一页排一份桌牌：上半联自动倒置、下半联正向，中间印好折线。字段只需在下半联设计（上半联实时镜像预览），打印后沿折线对折，立起来就是双面台签——**不需要打印机支持双面**。半页尺寸 = 纸张宽 × 纸张高的一半，A4 竖版折出来是 210×148.5mm 的标准桌牌。
- **排版工具**：字段拖拽自带吸附对齐（朱砂红辅助线）；选中多个字段后可用「均分横排」一键铺开；Ctrl+Z / Ctrl+Y 撤销重做，方向键微调。
- **画布缩放**：画布上方可缩小、放大、恢复到 100%，或按当前可用宽度自动适配；缩放范围为 25%–250%，放大后可在画布区域滚动查看细节。该设置只改变编辑视图，不会改变字段实际位置、字号或导出结果。

## 六、打印中心：出片与留痕

- **预览**：每次显示一张完整纸，上一页/下一页切换，总人数和总页数仍对应整个出片范围，缩放 50%~125%。
- **分批与进度**：大作业按整张纸分批，显示当前批次；照片默认每批 25 条，普通作业默认 100 条。全部批次完成后合并为一个 PDF；失败不会发布半成品。分批期间可点击「取消出片」，等待当前批次结束后停止后续输出；已提交打印队列的批次无法撤回。非静默直接打印每批确认打印机和设置。
- **打印前校验**：出片前自动扫一遍名单，四类问题会弹窗列出「哪个字段第几行」，**点行号自动跳到数据页对应格子直接补录**，补完回来接着打；也可以选择放行：空白位置留白打印、疑似占位值按原样打印、超宽文字会被版面裁掉、完全重复的行会打两份（同名多份属正常需求，确认名单没问题直接放行即可）。
- **出片范围你说了算**：默认打整份名单；要补打某几个人时，取消全选、按姓名搜索、勾选目标行即可。**部分出片只留痕、不改数据集的「已打」状态**——不会让你误以为整份都打完了。
- **出片**：一人一页，批量导出 PDF 或直接打印。纸张建议设「100% / 实际大小」并关闭页眉页脚。底图和上传字体都直接内置在出片内容里，导出的 PDF 和送印的内容在任何电脑上打开都不会丢底图。
- **历史**：每次成功打印自动归档内容快照（按月分目录），在应用内窗口即可回看原件、按原模板重打、可删除。点了打印又取消的不会落盘，历史里只留一条「取消」记录，不占空间。
- **删除历史的范围**：删除该任务记录、归档 HTML 和任务目录内的 `photos/` 照片副本，并同步历史恢复备份。已导出的 PDF、共享照片原件及缩略图、名单、模板、底图工程和累计打印状态保留。归档文件被占用时提示失败，保留记录供重试；路径异常时拒绝清理，不会删除其他任务或素材。恢复备份更新失败会单独提示。
- **统计**：统计条显示当前保留历史中的打印次数与最近时间；删除历史后这里的次数可能减少，「无记录」表示没有保留的记录。数据页「已打」来自名单的累计成功全量出片状态，删除历史不会将其变为未打。

## 七、更新与反馈

- 启动时会静默检查一次版本（只读版本号文件，不收集任何本机数据；离线则跳过，零打扰）。发现新版本会**在后台自动下载**，顶栏提示条显示「正在后台下载 N%」。
- 下载完成后，点提示条或「关于」里的**「立即重启安装」**即可升级；也可以在「关于」里点「检查更新」主动触发（下载中可随时看到进度）。
- **更新失败会在界面上直接写明原因**，不再悄无声息；实在不行点「前往发布页」手动下载覆盖安装，**数据不受影响**。
- 也可以随时在「关于」里提交问题反馈（直达 GitHub Issues，不要求注册任何账号以外的信息）。
- 「关于」里的「清理缓存与残留」一键做两件事：① 清掉浏览器内核产生的系统缓存（点完明确告诉你清了多少；其中 GPU 那两块被系统自己占着、当场删不掉，会自动排到**下次启动时清理**）；② **回收「已删除工程」留在磁盘上的残留版本文件**——工程在软件里删掉后，文件不会自动消失，长期会占地方。注意：残留是**曾经的数据、删了不可恢复**，所以点完会逐项报出清掉了几个；**正在用的工程绝不会被碰**。

## 八、常见问题

**打印整体位置偏移？** 打印对话框里缩放设为「100% / 实际大小」，关闭页眉页脚。

**导出 PDF 是白版？** 检查模板字段是否有标红「已失效」（绑定的数据集列被删了），删掉或换列后重新保存。

**换了电脑怎么搬数据？** 旧机拷贝 data 文件夹（或你自定义的目录）→ 新机安装批印坊 → 底部「更改…」指到该目录。

**同一个文件导入两遍会覆盖吗？** 不会。每次导入都是新建独立数据集，并排存在；不要的在数据页顶部下拉切到对应批次，一键整批删除即可。

**要补打名单里的几个人怎么操作？** 打印中心取消「全选」→ 在搜索框输入姓名 → 勾选目标行 → 出片。补打的部分只留痕，不会把整份名单标成「已打」。

**打一寸照 / 胸卡怎么排一页多个？** 模板工坊把版式切到「多联」，填成品尺寸（或用内置规格），自动算出每页几列几行；打完开裁切线手工裁即可。

**固定标题和边框怎么与姓名字段分开编辑？** 打开顶部「底图制作」，把标题、边框分别添加为文字或形状图层；回到模板页添加姓名等数据字段。

**保存了新版底图，为什么模板没变化？** 模板固定使用已应用的工程版本。回模板页选择新版本并应用，或从模板打开底图后点「保存并应用到模板」。

**导出 PNG 会影响工程或原图吗？** PNG 导出使用当前画布内容，不会创建新工程版本；工程中的原图素材仍按原文件保存。导出 PNG 是合成图片，如需之后分别编辑图层，请同时保存底图工程。

**旧版本为什么不自动升级？** 只有 0.2.13 及以后的版本带更新模块；更早的版本需要手动装一次，之后就都能自动更新了。
