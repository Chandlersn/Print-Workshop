# 批印坊 · 使用说明

> 给第一次拿到批印坊的你。从安装到打出第一批证书，大约十分钟。

## 一、安装

**系统要求**：Windows 10 / 11（64 位）。

**获取方式**：到 [GitHub Releases](https://github.com/Chandlersn/Print-Workshop/releases/latest) 下载最新安装包（`PrintPress-x.x.x-Setup.exe`）。两种形态任选：

- **安装版**（推荐）：双击安装包，按提示安装（可选安装位置，自动创建桌面和开始菜单快捷方式）；
- **免安装版**：解压后直接双击 `批印坊.exe`，不写注册表，删掉文件夹即卸载。

### 首次安装提示「Windows 已保护你的电脑」怎么办？

因为安装包没有购买代码签名证书，Windows SmartScreen 会对陌生程序出手，这是正常现象，**应用本身没有任何联网上传行为**。应对方法：

1. 在蓝色警告窗口点「更多信息」；
2. 出现「仍要运行」按钮，点击即可继续安装。

部分杀毒软件可能对免安装版报「未知程序」，加入信任列表即可。

### 数据在哪里？

所有数据（名单、模板、底图工程及素材、字体、打印记录）默认存在本机 `%APPDATA%\printpress\data`，**不上传任何服务器**。想放到 D 盘或网盘同步目录，打开应用后在底部「更改…」选择新位置即可，现有数据会自动迁移。备份或迁移时复制整个 data 文件夹。

## 二、四步打出第一批

首次启动自带**示例名单**，以及「底图制作」里 1 套排好位置的身份证参考版面，可以直接体验，也可以按下面四步用你自己的数据走一遍：

1. **导入名单**：打开「数据」页 → 点「导入」→ 选 Excel（.xlsx/.xls）或 CSV 文件。第一行会被当作表头，UTF-8 / GBK 编码自动识别。Excel 里有多个工作表时，可以选择每张表拆成独立数据集，或合并成一张。
2. **制作底图**（可选）：打开「底图制作」，把证书底图、固定文字与边框分别做成图层；直接用一张整图当底图也行，可跳过这步。
3. **设计模板**：打开「模板」页，上传一张证书底图（PNG/JPEG）或选用刚做好的图层工程；再选择数据集、把要打印的字段摆到画布上 → 保存。
4. **批量出片**：打开「打印中心」→ 选模板（自动带出绑定名单）→ 预览确认 → 导出 PDF 或直接送打印机。

## 三、数据页：名单管理

- **按「导入批次」管理**：每导入一次文件（含多工作表拆分出的全部数据集）就归为一个批次，侧栏顶部的「导入批次」下拉可以随时切换；删除按钮跟着批次走——多表导入的大文件想清掉，一键「删除整批（N 个工作簿）」即可，不用逐个删。
- **修改内容**：直接点击表格单元格编辑，Enter 提交、Esc 取消；支持加行、删行、翻页，表格字号四档可调。
- **「印」开关**：每个列头有一个单字「印」开关。**只有打开「印」的列，才会出现在模板设计的字段面板里**。没用的列不进设计器，避免干扰。激活过的数据集在侧栏显示「印 N」徽标并自动置顶。
- **打印状态一目了然**：打印或导出过的数据集整条变淡绿色并带「已打 N」旗标；没打过的保持白纸原样——要找遗漏，看哪条还是白的就行。选中数据集可在详情头看到「已打印 N 次，最近日期」。

## 四、底图制作：把版面做成图层

- **从图层底图开始**：点「新建底图」，设置工程名称、画布宽高和背景色；用左侧工具添加图片、固定文字、矩形、椭圆或直线。姓名、编号等随名单变化的内容仍应在「模板」页添加为字段。
- **本地素材库**：「底图制作」页顶部可打开「素材库」侧栏，把常用图片收进来跨工程复用——按名称/标签搜索、点标签筛选、★收藏、⊘归档（隐藏但**不删原件**）、✎改名改标签，点一张就放进当前画布。同一张图无论用在几个工程，磁盘上都只存一份原件；改库里的名字、归档某张图，都**不会改写已经引用它的旧工程**。工程里粘贴/拖入的图默认是「临时件」，删除图层会连带清理原件；想让它在删图层后仍保留，在图层行上点「＋」加入素材库即可（加入后受保护、不随删图层消失）。「清理未引用」会先列出既不在任何工程、也不在素材库的孤立原件，确认后才删。
- **编辑图层**：点选画布或左侧图层列表，在右侧用毫米数值精调位置、尺寸、旋转、不透明度、文字和颜色；也可直接拖动和调整尺寸。图片裁切只记录原图区域，不修改原文件。图层列表上方的项目会盖住下方项目，可调整顺序、显隐、锁定、复制或删除。
- **多选、分组与撤销**：按 Ctrl 或 Shift 点击图层可多选；方向键微调 0.1 mm，Shift 加速；拖动时可吸附，按住 Alt 暂时关闭吸附。至少选择两个图层后可组合，组可整体移动与对齐；当前支持一层分组。Ctrl+Z 撤销，Ctrl+Shift+Z 重做，Ctrl+S 保存。
- **工程版本与模板引用**：点击「保存工程」保存一个新版本；「另存副本」用来制作相似底图。模板会固定引用应用时的底图版本，之后保存工程的新版本不会自动改变模板。可在模板页选择新版本并应用，或从模板进入「编辑底图」，完成后点「保存并应用到模板」。工程尺寸不匹配时，先调整画布尺寸再应用；采用模板尺寸不会自动缩放现有图层。
- **从旧图片底图转换**：已有模板可以点击「将底图转为图层编辑」，把当前图片作为图片图层继续添加文字和形状。图片里已经合成的文字或边框不会自动拆成单独图层。
- **清晰度与 PNG 导出**：图层工程保留导入 PNG/JPEG 的原始文件内容，变换以参数记录；选中图片可查看按实际尺寸计算的有效 DPI。点击「导出 PNG」可选 150、300 或 600 DPI、透明背景并查看预计像素尺寸。透明导出会去掉画布底色，但图层中的白色矩形仍会输出。提高 DPI 不会增加低分辨率原图的细节；PNG 导出使用当前编辑稿，不会保存新工程版本。
- **参考线**：在右侧添加水平或垂直参考线并输入毫米位置；开启显示和吸附后，拖动图层可对齐参考线。按住 Alt 可暂时关闭吸附。参考线不会输出到 PDF 或 PNG。
- **完整操作说明**：图层属性、分组、参考线、草稿恢复和 PNG 限制见[底图制作使用说明](底图制作使用说明.md)。

## 五、模板工坊：版式设计

- **底图与纸张**：单张图片底图支持点画布中央上传、拖入图片文件，或按 Ctrl+V 粘贴剪贴板截图。也可以在顶部打开「底图制作」，把图片、固定文字与形状分别编辑。纸张可选 A3/A4/A5/B5/A6 预设或输入自定义毫米尺寸；模板采用多联或对折版式时，底图尺寸需要与单个成品或半页成品相符。
- **字体**：模板页「字体管理」可上传 TTF/OTF 字体。底图工程使用的上传字体在被工程或模板引用时受到删除保护；换电脑时应备份整个 data 文件夹。
- **保存有校验**：模板字段和所选数据集激活列必须匹配；字段失效或数据集未绑定时，模板保存或打印会提示处理。
- **多联拼版（打小件必看）**：打证件照、胸卡、桌牌这类小成品时，把版式从「单张」切到「多联」，填一下成品尺寸（内置 1 寸 / 2 寸 / 5 寸等常见规格，也可自由填毫米），系统自动算出每页能排几列几行并在纸上居中；画布随即切换成「单个成品」来设计，可以打开裁切线方便手工裁。工具栏里「纸张」和「成品」是两个独立维度——整张大纸和单个成品各自选预设或填毫米，自由组合。
- **对折桌牌（台签）**：版式切到「对折桌牌」后，一页排一份桌牌：上半联自动倒置、下半联正向，中间印好折线。字段只需在下半联设计（上半联实时镜像预览），打印后沿折线对折，立起来就是双面台签——**不需要打印机支持双面**。半页尺寸 = 纸张宽 × 纸张高的一半，A4 竖版折出来是 210×148.5mm 的标准桌牌。
- **排版工具**：字段拖拽自带吸附对齐（朱砂红辅助线）；选中多个字段后可用「均分横排」一键铺开；Ctrl+Z / Ctrl+Y 撤销重做，方向键微调。

## 六、打印中心：出片与留痕

- **预览**：整页无裁边预览，缩放 50%~125%。
- **打印前校验**：出片前自动扫一遍名单，四类问题会弹窗列出「哪个字段第几行」，**点行号自动跳到数据页对应格子直接补录**，补完回来接着打；也可以选择放行：空白位置留白打印、疑似占位值按原样打印、超宽文字会被版面裁掉、完全重复的行会打两份（同名多份属正常需求，确认名单没问题直接放行即可）。
- **出片范围你说了算**：默认打整份名单；要补打某几个人时，取消全选、按姓名搜索、勾选目标行即可。**部分出片只留痕、不改数据集的「已打」状态**——不会让你误以为整份都打完了。
- **出片**：一人一页，批量导出 PDF 或直接打印。纸张建议设「100% / 实际大小」并关闭页眉页脚。底图和上传字体都直接内置在出片内容里，导出的 PDF 和送印的内容在任何电脑上打开都不会丢底图。
- **历史**：每次成功打印自动归档内容快照（按月分目录），在应用内窗口即可回看原件、按原模板重打、可删除。点了打印又取消的不会落盘，历史里只留一条「取消」记录，不占空间。
- **统计**：统计条就放在打印历史上方，选中模板后显示该名单的历史打印次数与最近时间；没有记录时会标「无记录」——如果这份名单本来就要出片，那就是遗漏提醒，提醒和记录清单贴在一起对照。

## 七、更新与反馈

- 应用不会自动下载或安装任何更新。启动时会静默检查一次仓库里的版本号（仅读取版本号文件，不收集任何本机数据；离线则跳过，零打扰）。
- 有新版本时顶部会出现提示条，点「前往下载」到发布页获取新安装包，覆盖安装即可，**数据不受影响**。
- 也可以随时在「关于」里手动「检查更新」或提交问题反馈（直达 GitHub Issues，不要求注册任何账号以外的信息）。
- 浏览器内核运行产生的系统缓存可在「关于」中查看占用并一键清理，不会动你的任何业务数据。点完会明确告诉你清掉了多少；其中 GPU 那两块被系统自己占着、当场删不掉，会自动排到**下次启动时清理**（界面会写明还剩多少、什么时候清）。

## 八、常见问题

**打印整体位置偏移？** 打印对话框里缩放设为「100% / 实际大小」，关闭页眉页脚。

**导出 PDF 是白版？** 检查模板字段是否有标红「已失效」（绑定的数据集列被删了），删掉或换列后重新保存。

**换了电脑怎么搬数据？** 旧机拷贝 data 文件夹（或你自定义的目录）→ 新机安装批印坊 → 底部「更改…」指到该目录。

**同一个文件导入两遍会覆盖吗？** 不会。每次导入都是新建独立数据集，并排存在；不要的在数据页顶部下拉切到对应批次，一键整批删除即可。

**要补打名单里的几个人怎么操作？** 打印中心取消「全选」→ 在搜索框输入姓名 → 勾选目标行 → 出片。补打的部分只留痕，不会把整份名单标成「已打」。

**打一寸照 / 胸卡怎么排一页多个？** 模板工坊把版式切到「多联」，填成品尺寸（或用内置规格），自动算出每页几列几行；打完开裁切线手工裁即可。

**固定标题和边框怎么与姓名字段分开编辑？** 打开顶部「底图制作」，把标题、边框分别添加为文字或形状图层；回到模板页添加姓名等数据字段。

**保存了新版底图，为什么模板没变化？** 模板固定使用已应用的工程版本。回模板页选择新版本并应用，或从模板打开底图后点「保存并应用到模板」。

**导出 PNG 会影响工程或原图吗？** PNG 导出使用当前画布内容，不会创建新工程版本；工程中的原图素材仍按原文件保存。导出 PNG 是合成图片，如需之后分别编辑图层，请同时保存底图工程。
