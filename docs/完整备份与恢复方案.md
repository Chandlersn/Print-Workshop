# 完整备份与恢复方案

> 设计基线：2026-11-15，工作区 v0.7.2。本文件是待实现、待演练的方案，不表示软件已经提供一键完整备份或恢复。

## 目标与已有能力

用户可以把一份可验证的工作环境备份到其他磁盘，并在本机新目录或另一台兼容的 Windows 电脑恢复，重新打开名单、照片、模板、单人海报和历史快照。备份须明确大小和范围；恢复失败不得破坏原数据。打印记录和快照用于回看，历史重打仍可能使用当前名单及模板，不能承诺历史输出完全一致。

现有[数据目录迁移](../electron/data-dir.cjs)是在重启时复制并保留原目录；[底图工程包](../electron/design-package.cjs)只转移工程和相应素材。两者都不是本方案中的完整备份。独立素材目录由环境变量 `PRINTPRESS_ASSET_DIR` 指定，不能假定它位于数据目录内，见[素材存储](../electron/asset-storage.cjs)。

## 数据边界

第一期建议按完整数据目录收集业务文件，而非手工维护易遗漏的 JSON 白名单；另行收集实际启用的独立素材池。清单必须列出文件、逻辑来源、大小和 SHA-256，并记录应用版本、备份格式版本、创建时间及功能范围。对不认识的新业务文件默认保留并标记，不能静默丢弃。

| 内容 | 备份要求 |
| --- | --- |
| 名单、稳定人员 ID、模板、字段与关联、设置、照片关联、照片处理状态、单人位置和单人底图关联、素材库及打印记录等数据文件 | 纳入，连同仍有恢复价值的 `.bak` 和损坏留存文件；恢复验证不得覆盖证据。 |
| `designs/`、`individual-designs/`、`photo-assets/`、`ephemeral-assets/`、`print-bg/`、`print-fonts/`、历史 `archive/` 中的快照及其相对照片文件 | 纳入；保留目录结构及引用关系。`ephemeral-assets` 也可能被引用，不按名称直接排除。 |
| `design-assets/` | 默认数据目录内时纳入；外置时从实际外置路径另外复制，确保清单说明来源。若还存在旧位置文件也应盘点并保留，不能擅自判定无用。 |
| 缩略图和其他缓存 | 仅对确认可重建、且不承载唯一业务内容的缓存允许排除；未核实的目录先保留。不得清理源文件。 |
| 导入或工程包暂存、事务日志、锁及临时文件 | 先结束或恢复未完成事务；排除正在使用的锁和确定不属于快照的临时文件。若事务状态无法确定则中止并提示，不得备份为成功。具体排除规则须逐项测试。 |
| 数据目录之外的引导文件 `data-dir.json`、环境变量、系统路径 | 不原样恢复旧机器的绝对路径；清单只记录逻辑布局，恢复时依据新位置生成有效配置。 |
| 编辑器未保存草稿 | 当前草稿存在渲染器 `localStorage`，不在数据目录内；第一期要求用户先保存工程，并明确提示未保存草稿和内存撤销历史不包含在备份中。不能宣称包含全部草稿。 |
| 界面偏好、浏览器缓存、应用程序和模型 | 不默认承诺迁移；清晰列明不包含项目。应用和所需模型由兼容版本安装提供；字体文件若属于用户上传则必须纳入。 |

名单和照片包含个人信息；备份是可读取的本地文件，目标位置、传输方式及删除由用户控制。第一期不承诺加密；如以后增加加密，密码丢失不可恢复的影响须单独设计。

## 一致性和备份流程

1. 读取当前实际数据目录与外置素材目录，检查可访问性、路径包含关系和磁盘空间，计算预计大小。备份目标及其临时目录不得位于被复制的源目录中；也不得把源目录作为目标。空间估算包括暂存、最终文件及安全余量。
2. 提示保存草稿，阻止新导入、编辑保存、出片归档、素材清理和照片后台任务；等待正在运行的任务完成或明确取消，确认事务已恢复。进程锁只能防止其他实例，不能单独保证同一进程的异步写入停止。若无法建立全局静止点，则第一期改用应用关闭后的独立备份助手并持有同一数据锁，不能边复制边声称快照一致。
3. 在目标的独立临时目录分块复制并计算哈希，按逻辑根隔离外置素材；限制内存占用，展示阶段、进度及可取消状态。禁止跟随符号链接、联接点或重解析点越界；遇到无法安全判断的路径中止并报告。
4. 在暂存副本上校验文件数、长度、哈希与必要引用；只读解析，不对源数据调用会自动修复或改名的 `loadJson`。源发生变化、外置盘断开、权限或空间不足时标记失败，保留原数据。
5. 校验通过后，以同一目标卷上的原子重命名发布备份和清单；发布前可取消并清理本次暂存，发布后显示实际路径与校验结果。中断残留仅按任务标识清理，不删除其他文件。

具体封装形式（目录或归档）及静止点实现须在开发时确定；若使用归档，解包时同样禁止绝对路径、`..`、链接和重复路径覆盖，并设置大小及文件数限制。

## 恢复与切换

1. 先只读检查格式、版本、清单与哈希，给出备份时间、来源版本、体积、草稿和配置未覆盖项。新版本备份被旧程序打开、清单损坏或必需素材缺失时停止恢复；版本迁移只能在副本中执行，需建立明确的兼容矩阵及迁移测试。
2. 由用户选一个全新空目录，检查可写、空间、路径重叠、重解析点和占用；禁止覆盖、合并或清空现有工作目录。将文件恢复到隔离的同卷暂存目录，复核哈希、JSON 结构、引用和历史快照相对文件。
3. 外置素材恢复默认建议复制到新数据目录下的 `design-assets/`，但必须在试运行中验证解析器及旧位置混合情况；若用户选择独立素材目录，则需要新的有效绝对路径及启动配置。现有环境变量优先级必须检查，不能在外置变量仍生效时误以为已切换到内置池。
4. 用隔离配置启动兼容应用，核验名单、照片、模板、单人海报和历史快照；此阶段不可改动当前工作环境。只有校验与试运行通过，且用户明确选择切换后，才通过带日志的原子配置更新指向新目录并重启。配置切换失败或崩溃时保留旧配置和原数据，可重新进入旧环境。
5. 恢复不自动删除备份、旧数据或未选择的外置素材。显示恢复位置、版本和结果；临时文件清理由任务日志限定范围。

## 可执行验收样例

以下均使用隔离测试目录和合成数据，不触碰用户现有数据。每条分别记录版本、输入、操作、期望及结果。

| 场景 | 输入和操作 | 验收结果 |
| --- | --- | --- |
| 跨目录完整恢复 | 两人名单、共享原图、已保存模板、单人海报及照片例外、上传字体、打印记录和含相对照片的历史快照；备份后恢复到新目录 | 哈希和引用校验通过；打开人员、模板、单人预览及历史快照，生成预览与 PDF，核对人数和页面。旧目录内容未变化。 |
| 外置素材和跨机器 | 素材池位于另一目录；搬运备份到模拟新机器的不同路径恢复 | 内置及可选外置恢复方式均能正确读取素材；旧绝对路径不被依赖，环境变量冲突须被提示。 |
| 草稿与配置 | 保存一个工程，同时保留未保存编辑草稿和用户界面偏好 | 备份前明确提示草稿不包含；恢复后保存工程可打开，不声称草稿已恢复。 |
| 中断及并发 | 导入、处理或归档进行时开始备份；分别在复制和发布前中断 | 不能发布混合状态；任务按静止规则等待/取消或阻止；原目录完整，残留可安全识别。 |
| 异常输入 | 缺少外置盘、空间不足、备份文件缺失或篡改、权限不足、目录嵌套、符号链接、恶意归档路径、已有目标 | 明确失败且不覆盖源与目标；不得显示备份或恢复成功。 |
| 版本与切换 | 用不兼容版本、损坏清单及中断配置切换模拟恢复 | 不兼容或损坏时阻止；切换失败仍能重新进入原目录；试运行未通过时不切换。 |

设计完成不等于验收完成。当前尚未实现上述完整备份、恢复和隔离试运行，也尚未执行跨机器恢复演练。
