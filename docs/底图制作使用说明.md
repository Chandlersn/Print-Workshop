# 底图制作使用说明

底图制作适合证书、奖状、胸卡和桌牌的固定内容排版。图片、标题、边框、固定说明分别保存为图层，之后可以继续修改。姓名、编号等每个人不同的内容，仍在模板页添加变量字段。

## 新建和编辑

打开顶部「底图制作」，点击新建，填写工程名、画布宽高和背景色。尺寸单位是毫米。制作多联胸卡时填写一张胸卡的尺寸；制作对折桌牌时填写半页尺寸。

添加图片、文字、矩形、椭圆或直线。图片也可以直接 Ctrl+V 粘贴截图，或把图片文件拖进画布，省去先点「＋ 图片」再选文件的步骤；粘贴与拖拽只接受 PNG/JPEG，其他格式会提示且不会新增图层。点选画布或左侧图层列表中的图层，在右侧属性栏调整位置、尺寸、角度、透明度、文字或颜色。图片默认等比缩放；裁切输入的是原图区域的百分比，原图片文件不会被裁掉。文字尺寸框决定换行及裁切范围，文字过多时请增大文字框。

拖动画布上的图层移动，拖动控制点调整尺寸。**双击文字图层就能像改 PPT 文本框那样在画布上直接改字**：原位出现一个虚线编辑框，里面的字号、行距、颜色和打印出来的完全一致，所见即所得；进入时整段选中，想重写就直接打字，想微调点一下取消选中。改完点编辑框以外的任何地方就收工（右侧面板、工具栏、画布空白都算），也可以按 Esc 收工（Esc 保留改动，想撤销按 Ctrl+Z）；改完直接按 Ctrl+S 也会先把文字落定再存盘。按住 Ctrl 或 Shift 点选多个图层，可一起移动和对齐。方向键微调位置；Ctrl+Z 撤销，Ctrl+Y 重做。一次拖动对应一步撤销。

图层列表上方的图层覆盖下方图层。可调整顺序、显示、锁定、复制和删除。锁定图层不会被误拖动；隐藏图层不会打印。删除图层后可以撤销恢复。

## 图层分组

按 Ctrl 或 Shift 多选至少两个图层，点击「组合所选」或按 Ctrl+G。点组名或画布上的组成员可选中整组；在右侧修改分组名称。整组可以移动、对齐、复制、显隐和锁定，成员保持相对位置。点击「解除分组」或按 Ctrl+Shift+G，会保留各图层的位置与外观。

在左侧列表点击组内某个成员，可以单独修改其属性、用方向键微调、对齐、复制或删除。只选一个成员时，这些操作只作用于该成员；删除后组内不足两层，会自动解组。调整图层顺序需先点组名选中完整分组。组内任一成员锁定时，整组移动、排序、删除和成员属性编辑均受保护，需先解锁。

本版支持一层分组，暂不支持嵌套分组或整组缩放、旋转。带分组或参考线的工程使用格式版本 2，需用 v0.4.0 或更新的兼容版本打开；已有旧工程仍可照常使用。

## 参考线

在右侧「参考线」选择垂直线 X 或水平线 Y，输入距画布左边或顶部的毫米位置，再点击添加。已有参考线可直接修改位置，或点击 × 删除。缩小画布后，落到范围外的参考线仍保留在列表，并标记「画布外」。

开启「显示并吸附参考线」及画布顶部的「吸附」后，拖动图层会吸附到参考线；按住 Alt 拖动可暂时关闭吸附。参考线的增删与位置支持撤销，并随工程保存。参考线、选中框和操作手柄都不会出现在 PNG 或 PDF 中。

## 保存和应用

保存会生成一个新的工程版本。另存副本用于制作相似底图；从引用旧版本的模板进入编辑时，如果该工程已有更新版本，请打开最新版或另存副本。

在模板页选择已保存的图层工程，再保存模板。也可从模板进入「编辑底图」，完成后保存并应用。工程尺寸必须与模板的成品尺寸相同；尺寸不同会提示调整，避免自动拉伸。

模板固定引用应用时的版本。例如模板使用第 2 版底图，之后保存第 3 版不会自动改变这个模板，需主动选用或应用第 3 版。已经归档的打印内容也不会被改写。

旧模板的图片底图可以复制为一个锁定图片图层，再添加新内容。已经合成在旧图片里的文字、边框不能自动拆成可编辑图层。

## 清晰度与字体

导入的 PNG/JPEG 保留原文件字节，缩放、旋转与裁切保存为编辑参数。编辑器显示缩小不代表原素材被缩小。选择图片时会显示按实际打印尺寸计算的有效 DPI；放大低分辨率图片无法增加细节。

PDF 直接使用图片素材、固定文字和形状，变量字段继续由名单生成。打印中心显示底图版本及图片最低有效 DPI。字体加载失败或工程素材缺失时应先修复资源，再输出。

已保存工程使用的上传字体受到删除保护。跨电脑转移时仍应完整备份数据目录和使用的字体；仅复制工程 JSON 不包含图片文件。

## 导出高清 PNG

点击顶部「导出 PNG」，选择 150、300 或 600 DPI（默认 300），查看预计像素尺寸，再选择保存位置。A4 竖版在 300 DPI 下为 2480×3508 像素，600 DPI 下为 4961×7016 像素。提高导出 DPI 能让文字和形状获得更多像素，但无法增加低分辨率原图本身的细节。

「透明背景」会忽略画布底色，保留图片和图层自身的透明度；已有白色矩形等图层仍会显示。隐藏图层不输出。PNG 为无损编码的单张合成图，包含物理 DPI 信息；若需继续调整图层，应同时保存工程。

导出使用当前编辑稿，无需先保存，也不会创建新工程版本或清除未保存标记。工程中的原图片仍保留原始字节。PDF 继续直接排版图层素材、文字和矢量形状。

单边超过 16384 像素、总像素超过 4000 万，或预计工作内存超过 768 MB 时，导出会明确提示，可降低 DPI、缩小画布或减少大图。取消保存不会写文件；导出失败会保留目标位置原有文件。

## 草稿与工程删除

编辑器保留未保存的本地恢复草稿，切换页面后可继续编辑。需要长期保留或备份的内容请点击保存，恢复草稿不能替代工程保存。

工程被模板引用时不能删除，需先从这些模板移除引用。当前保守保留图片原件与历史版本文件，避免删除图层或撤销操作后素材丢失，因此删除工程不保证立即回收所有磁盘空间。

## 当前范围

支持 PNG/JPEG、固定文字、基础形状、一层图层分组、参考线及独立 PNG 导出。PSD/Compositor 工程互开、复杂滤镜、蒙版、嵌套分组与专业印刷色彩管理不属于本版功能。
