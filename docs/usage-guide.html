批印坊

使用说明 · v0.1.0 · 本地离线批量打印工具

一、安装

系统要求：Windows 10 / 11（64 位）。两种形态任选：

  • 安装版：双击 批印坊 Setup x.x.x.exe，按提示安装，自动创建桌面和开始菜单快捷方式；
  • 免安装版：解压后直接双击 批印坊.exe，不写注册表，删掉文件夹即卸载。

提示「Windows 已保护你的电脑」怎么办？

安装包未购买代码签名证书，Windows SmartScreen 会对陌生程序出手，属正常现象，应用没有任何联网上传行为。 应对：在蓝色警告窗口点「更多信息」→ 出现「仍要运行」按钮 → 点击继续。个别杀软误报「未知程序」，加入信任列表即可。

数据在哪里？

所有数据（名单、模板、打印记录）默认存在本机 %APPDATA%\批印坊\data，不上传任何服务器。 想放 D 盘或网盘同步目录：应用底部「更改…」选择新位置，现有数据自动迁移。备份 = 拷贝整个 data 文件夹。

二、三步打出第一批

首次启动自带 4 套示例模板和示例名单，可直接体验；用你自己的数据按下面三步走：

  1. 导入名单：「数据」页 → 导入 → 选 Excel（.xlsx/.xls）或 CSV。首行作表头，UTF-8 / GBK 自动识别；Excel 多工作表可拆分成多个数据集或合并成一张。
  2. 设计模板：「模板」页 → 上传证书底图（png/jpg）→ 左侧字段面板点选字段，拖到画布摆好 → 保存。
  3. 批量出片：「打印中心」→ 选模板（自动带出绑定名单）→ 预览确认 → 导出 PDF 或直接打印。

三、数据页：名单管理

  • 修改内容：点击单元格直接编辑，Enter 提交、Esc 取消；支持加行、删行、翻页，字号四档可调。
  • 「印」开关：列头单字开关，只有打开「印」的列才会出现在模板字段面板；激活过的数据集显示「印 N」徽标并自动置顶。
  • 打印状态：打印或导出过的数据集整条淡绿色并带「已打 N」旗标；没打过的保持白纸——找遗漏，看哪条还是白的。

四、模板工坊：版式设计

  • 底图与纸张：上传底图自动按比例建议纸张（A3 / A4 / A5 横竖版），比例差太多会预警。
  • 排版：拖拽自带吸附对齐（朱砂辅助线）；多选后「均分横排」「列对齐」一键铺开；Ctrl+Z 撤销、方向键微调。
  • 字体：左侧「字体管理」上传 ttf/otf 内置到模板（推荐猫啃网免费商用字体，应用内有直达链接）。
  • 保存校验：模板字段与数据集激活列必须一一对应，对不上拒绝保存并点名缺失字段——杜绝白版。

五、打印中心：出片与留痕

  • 预览：整页无裁边，缩放 50%~125%。
  • 打印前校验：空白字段弹窗列出「哪个字段第几行」，点行号直达数据页那格补录；也可放行（空白留白打印）。
  • 出片：一人一页批量导出 PDF 或直打；打印对话框建议设「100% / 实际大小」并关闭页眉页脚。
  • 历史：每次打印自动归档快照（按月分目录），可回看、重打、删除。
  • 统计：显示该名单历史打印次数与最近时间；显示「无记录」——就是还没打过。

六、更新与反馈

  • 应用不会自动下载或安装更新。启动时静默检查一次仓库版本号（仅读版本号文件，不收集本机数据；离线跳过）。
  • 有新版本时顶部出现提示条，「前往下载」到发布页获取新包覆盖安装，数据不受影响。
  • 也可在「关于」里手动「检查更新」或提交问题反馈。

七、常见问题

问题解答
打印整体位置偏移？打印对话框缩放设「100% / 实际大小」，关闭页眉页脚。
导出 PDF 是白版？模板字段有标红「已失效」（绑定列被删），删掉或换列后重新保存。
换电脑怎么搬数据？拷贝 data 文件夹 → 新机安装后底部「更改…」指到该目录。
同一文件导入两遍会覆盖吗？不会。每次导入都是新建独立数据集；不要的在数据页单独删除。
